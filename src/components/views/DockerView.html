🐳 Production Docker for Go (The Node.js Contrast)

Why Go Docker images are legendary: Single static binaries, zero runtime, sub-15MB container images, and no 500MB node_modules security vulnerabilities.

⚖️ Docker Image Comparison: Node.js vs Go

Metric / Feature Node.js Docker Container Go Docker Container (Distroless / Scratch)
Final Image Size 180 MB – 1.2 GB (Base OS + Node + node_modules) 5 MB – 18 MB (Single static compiled binary)
Runtime Requirements Node.js engine, V8, libuv, npm dependencies Zero runtime. Direct Linux kernel ELF binary.
Base Image node:20-alpine or node:20-slim gcr.io/distroless/static or scratch
Attack Surface & CVEs Hundreds of npm packages & C++ runtime CVEs Zero package manager, zero shell, zero CVEs.
Cold Start Memory ~50 MB – 120 MB RAM at idle ~5 MB – 15 MB RAM at idle
🏆 1. Gold Standard: Google Distroless Multi-Stage Dockerfile

Recommended for enterprise production. Runs as a non-root user (UID 65532), includes official CA certificates for outbound HTTPS calls, and tzdata for timezones. 

# --- Stage 1: Build the Static Binary ---
FROM golang:1.23-alpine AS builder

# Install ca-certificates and git in builder if needed
RUN apk --no-cache add ca-certificates git

WORKDIR /app

# Cache dependencies layer
COPY go.mod go.sum ./
RUN go mod download

# Copy source code
COPY . .

# Build ultra-compact, stripped static Linux binary
# CGO_ENABLED=0  -> Pure Go network resolver, no libc dependency
# -ldflags="-s -w" -> Strip debugging symbols & DWARF tables (35% size reduction)
# -trimpath      -> Remove local filepath metadata from binary
RUN CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build     -ldflags="-s -w -X main.Version=1.0.0"     -trimpath     -o /app/server ./cmd/main.go

# --- Stage 2: Final Minimal Runtime (< 15MB) ---
FROM gcr.io/distroless/static-debian12:nonroot

WORKDIR /app

# Copy binary from builder
COPY --from=builder /app/server /app/server

# Expose HTTP port
EXPOSE 8080

# Run as non-root user (UID 65532 built into distroless)
USER nonroot:nonroot

ENTRYPOINT ["/app/server"]
⚡ 2. Ultra-Minimal: Scratch Dockerfile (~6 MB Total Image)

The smallest conceivable container image. FROM scratch has zero files; we copy CA certs from the alpine builder so outbound HTTPS webhooks and database TLS work. 

# Builder stage
FROM golang:1.23-alpine AS builder
RUN apk --no-cache add ca-certificates tzdata && \
    adduser -D -u 10001 -g "" appuser
WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download
COPY . .
# CGO_ENABLED=0 with GOOS=linux GOARCH=amd64 ensures fully portable static ELF binary
RUN CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -ldflags="-s -w" -trimpath -o /app/server .

# Final stage: completely empty scratch container (<15MB)
FROM scratch

# Copy unprivileged user and group mappings
COPY --from=builder /etc/passwd /etc/passwd
COPY --from=builder /etc/group /etc/group
USER 10001:10001

# Copy SSL certificates for outbound HTTPS calls
COPY --from=builder /etc/ssl/certs/ca-certificates.crt /etc/ssl/certs/

# Optional: copy timezone data if loading timezones via time.LoadLocation
# (Or compile with blank import: _ "time/tzdata")
COPY --from=builder /usr/share/zoneinfo /usr/share/zoneinfo/

# Copy binary
COPY --from=builder /app/server /server

EXPOSE 8080
ENTRYPOINT ["/server"]
