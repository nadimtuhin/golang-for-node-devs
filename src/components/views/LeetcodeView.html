🟢 #206. Reverse Linked List (Pointers)

JS Approach: let prev = null, curr = head pointer swapping.

Go Approach: In-place pointer reversal nextTemp := curr.Next; curr.Next = prev; prev = curr; curr = nextTemp.

O(N) Time • O(1) Space • Memory Pointer Flipping
