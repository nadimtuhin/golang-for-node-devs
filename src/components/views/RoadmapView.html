Go Developer Roadmap (roadmap.sh)

The definitive community-standard roadmap.sh/golang learning curriculum mapped directly to our 60 interactive chapters, runnable code playgrounds, and 14 production architecture guides. Transition smoothly from Node.js & TypeScript into idiomatic, high-scale Go engineering.

TL;DR: The roadmap moves a Node/TypeScript developer to production Go in 7 stages. Stage 1 swaps TS habits for Go's syntax, explicit error returns and structural interfaces. Stage 2 covers slices, maps, pointers and memory layout. Stage 3 replaces the event loop and Promise.all with goroutines, channels and context. Stage 4 builds HTTP APIs with net/http in place of Express. Stage 5 adds database connection pools and background queues. Stage 6 swaps Jest for go test and table-driven tests. Stage 7 ships static binaries in distroless images under 15 MB and builds AI agents as MCP servers.
