📦 Dependency Management: Go Modules vs npm

How go.mod and go.sum replace package.json, package-lock.json, and the node_modules folder.

📄 1. package.json vs go.mod

In Node, package.json lists package names and semantic version ranges registered on npmjs.org.

In Go, there is NO centralized npm registry. go.mod declares dependencies using direct Git repository paths (e.g., github.com/gofiber/fiber/v2).

🔒 2. package-lock.json vs go.sum (Cryptographic Security)

go.sum is a cryptographic SHA-256 ledger. If a package author deletes their repo or force-pushes a malicious change to a Git tag (supply chain attack), the Go compiler detects the mismatch and aborts the build.

🗑️ 3. Where is node_modules?

Go never creates a local dependency folder in your project. Dependencies are downloaded once globally to $GOPATH/pkg/mod/ and shared across all projects.
